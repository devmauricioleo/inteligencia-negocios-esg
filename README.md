\# Inteligência de Negócios para Sustentabilidade (ESG)



\## Sobre o projeto



Projeto acadêmico desenvolvido com o objetivo de centralizar, organizar e analisar indicadores de sustentabilidade (ESG), utilizando conceitos de Business Intelligence e Data Warehouse.



A solução permite acompanhar indicadores ambientais, sociais, econômicos e de governança, auxiliando na análise de desempenho e na tomada de decisões.



\## Tecnologias utilizadas



\- PostgreSQL — armazenamento e gerenciamento dos dados.

\- Modelo dimensional (Star Schema) — organização dos dados para análise.

\- Power BI — criação de dashboards e visualização dos indicadores.



\## Estrutura do projeto



\- `database/`: scripts SQL e estrutura do banco de dados.

\- `powerbi/`: relatório e dashboards desenvolvidos no Power BI.

\- `docs/`: documentação técnica do projeto.



\## Dashboards



1\. Visão Geral ESG.

2\. Desempenho Ambiental.

3\. Desempenho Social.

4\. Governança e Econômico.



\## Objetivo



Transformar dados de sustentabilidade em informações úteis para o acompanhamento de indicadores, avaliação de metas e apoio à tomada de decisões.
